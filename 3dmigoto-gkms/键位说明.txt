GakumasMI / 3DMigoto 键位说明
================================

常用键
------
F10        重载 Mods。改了 mod 文件后按一下即可生效，无需重启游戏。
F9         临时显示原始模型（按住时隐藏 mod，松开恢复）。
F8         抓帧分析（导出当前帧数据，mod 作者调试用，普通玩家用不到）。

关于屏幕左上角的绿色文字
------------------------
那是 3DMigoto 的调试 HUD（hunting 模式），显示当前 shader / buffer 信息，
只是遮挡画面，不影响游玩。

本插件默认已关闭它（d3dx.ini 里 hunting=2）：
  - 绿字默认不显示；
  - F10 / F8 / F9 依然可用；
  - 需要调试时，按【小键盘 0】临时打开绿字，再按一次关闭。

小键盘按键（仅在绿字打开后有意义，mod 作者抓帧调试用）
----------------------------------------------------
  小键盘 0            开关 hunting 调试模式（绿字）
  小键盘 1/2/3        上一个 / 下一个 / 标记 像素着色器
  小键盘 4/5/6        上一个 / 下一个 / 标记 顶点着色器
  小键盘 7/8/9        上一个 / 下一个 / 标记 索引缓冲
  小键盘 / * -        上一个 / 下一个 / 标记 顶点缓冲
  （按住小键盘“.”再按上面的键 = 操作 compute/geometry 等其它着色器）

说明
----
- 以上键位都由游戏目录的 d3dx.ini [Hunting] 段控制，一般不需要手动改。
- 想彻底关掉这些调试键（连 F10 也不要）可把 hunting 设为 0；想常显绿字设为 1。
