Gakumas 3DMigoto 抓帧环境 键位说明
====================================

这个包只做一件事：给 mod 作者抓帧（Frame Analysis），用来生成 GakumasMI 的配置档。
它不加载 mod。换模走 AB bundle 路线，由 xinput1_3.dll（gakumas-mod-runtime）负责，
和这个加载器无关。

常用键
------
F8         抓帧分析 —— 导出当前帧的 buffer / 贴图 / shader 到游戏目录的
           FrameAnalysis-<日期时间>\ 文件夹。这是本包的主要用途。
F10        重载 d3dx.ini 与 ShaderFixes。改了配置或 shader 后按一下即可生效，
           无需重启游戏。
F9         按住时显示原始画面（本包不加载 mod，所以一般看不出差别）。

关于屏幕左上角的绿色文字
------------------------
那是 3DMigoto 的调试 HUD（hunting 模式），显示当前 shader / buffer 信息，
只是遮挡画面，不影响游玩。

本包默认已关闭它（d3dx.ini 里 hunting=2）：
  - 绿字默认不显示；
  - F10 / F8 / F9 依然可用；
  - 需要定位具体 draw 时，按【小键盘 0】临时打开绿字，再按一次关闭。

小键盘按键（仅在绿字打开后有意义，抓帧定位 draw 用）
--------------------------------------------------
  小键盘 0            开关 hunting 调试模式（绿字）
  小键盘 1/2/3        上一个 / 下一个 / 标记 像素着色器
  小键盘 4/5/6        上一个 / 下一个 / 标记 顶点着色器
  小键盘 7/8/9        上一个 / 下一个 / 标记 索引缓冲
  小键盘 / * -        上一个 / 下一个 / 标记 顶点缓冲
  （按住小键盘“.”再按上面的键 = 操作 compute/geometry 等其它着色器）

说明
----
- 以上键位都由游戏目录的 d3dx.ini [Hunting] 段控制，一般不需要手动改。
- 想彻底关掉这些调试键（连 F10 也不要）可把 hunting 设为 0；想常显绿字设为 1。
- d3dx.ini 顶部的 include_recursive = Mods 已注释掉 —— 本包不加载 mod。旧的
  3DMigoto mod 若还想用，取消注释并自建 Mods 目录，但该路线已不再维护。
