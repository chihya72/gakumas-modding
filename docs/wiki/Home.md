# GakumasMI 作者手册

这套工具用于制作《学园偶像大师》的本地 body 与 hair AssetBundle Mod。作者侧只使用 Blender 和 GakumasMI 插件；成品由独立的 Gakumas Mod Runtime 加载。3DMigoto 在这里仅负责抓帧，不负责加载 Mod。

按这个顺序读：

2. [[先了解插件会做什么、不会做什么|2-插件负责什么]]

## 当前产品边界

GakumasMI 只走 AssetBundle 路线。插件不从参考身体传递权重，也不会自动完成删头、全身对齐、UV 图集或坏权重修复。作者模型必须自带骨架和有效权重；插件负责准备目标资料、把源骨映射到游戏骨、生成游戏贴图数据、执行导出闸门并打包。

支持 Blender 4.2 LTS 与 4.5 LTS，两者都在自动测试范围内。
