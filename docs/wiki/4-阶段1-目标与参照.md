# 4. 阶段 1：目标与参照

这一阶段只回答两个问题：要替换哪个游戏资源，以及后续用哪套原版网格和骨架作为参照。

## 4.1 第一次替换这个目标

`目标来源` 选择 `从抓帧新建`。主流程有三个输入：

| 字段 | 填什么 | 是否必填 |
|---|---|---|
| 抓帧目录 | 目标服装或发型出现时按 F8 得到的 `FrameAnalysis-*` | 是 |
| 身体或发型 JSON 资源库 | 对应的 `assetstudio-body-json` 或 `assetstudio-hair-json` 根目录 | 是 |
| 目标 body 或 hair 资源 | 角色代号或完整资源名，用于多个候选之间消歧 | 否 |

点击 `生成配置档并导入目标参照`。这个按钮会先建立完整配置档，再导入带权重参考网格与骨架；任一步失败都不会自动进入下一阶段。

未指定 `新配置档输出` 时，配置档默认写到：

```text
<抓帧目录>\GakumasMI-profile\
```

抓帧目录以后可能被清理。首次生成成功后，建议把完整配置档复制到项目自己的长期目录，再在项目中记录路径。

## 4.2 复用已有配置档

同一个目标不需要每次重新抓帧。`目标来源` 选择 `使用已有配置档`，填写 `配置档目录`，点击 `导入目标参照`。

复用配置档不会重新解析抓帧，也不会自动改成当前角色身上的其他资源。确认配置档对应的角色、服装编号和组件与本项目一致。

## 4.3 导入后应该看到什么

成功后场景里会出现原版参考网格和骨架。它们的用途是：

- 给作者模型提供空间、姿势和尺寸基准；
- 提供目标骨名和骨架层级；
- 给肤色对齐、部分描边数据和导出体检提供依据。

参考网格不是作者模型。不要编辑它代替自己的网格，也不要在导出前删除。阶段 2 会单独选择真正的作者模型。

## 4.4 自动匹配不对时

常见表现是导入了尺寸相近但服装编号不同的参考体，或提示有多个候选。

优先做法：

1. 回到主流程，在 `目标 body 资源（可选）` 或 `目标 hair 资源（可选）` 填完整资源名；
2. 重新点击主按钮生成配置档；
3. 检查导入对象名、轮廓和组件是否与游戏中抓到的目标一致。

只有资源名仍无法消歧时，才打开 `高级 / 分步 / 排错`，在 `主 Draw` 填抓帧对应的 Draw 编号，再重新生成。`0` 表示继续自动选择。

## 4.5 高级区什么时候用

`高级 / 分步 / 排错` 不是正常制作顺序：

| 操作 | 用途 |
|---|---|
| 只生成或重新生成完整配置档 | 需要重建文件，但暂时不导入场景 |
| 仅生成注入信息 | 检查抓帧解析，不补权重骨架 |
| 仅匹配资源库 | 查看抓帧最终命中了哪个 JSON 资源 |
| 换新抓帧校验并更新配置档 | 游戏更新后用新抓帧核对既有目标 |
| 导入配置档全部对象 | 排查配置档内容 |
| 只导入抓帧参考模型 | 导入无权重的几何对照 |

正常项目只使用本页顶部的一个主按钮。分步操作成功不等于完整配置档已经可用于导出。

## 4.6 红色提示

- `没有抓帧目录`：当前走从抓帧新建，但 `抓帧目录` 为空。
- `没有网格 JSON 资源库`：没有可用于补全网格、权重和骨架的数据。
- `没有配置档目录`：当前走复用路线，但未选择 profile。

这三项只检查路径是否填写；路径内资源是否匹配，要等主按钮实际运行后才能确定。
