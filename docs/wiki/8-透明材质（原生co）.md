# 8. 透明材质（原生 co）

需要做透明 / 镂空部件（薄纱袖、镂空裙等）时看这页。当前**唯一支持的透明路线**是借用游戏原版自带的透明部件来画。

## 8.1 `渲染材质` 的两档

材质属性 `渲染材质` 有两档：

- **不透明**：普通 body，投影 / 遮挡 / 描边最稳定；
- **原生 co**：借用游戏原版的透明部件来画你的透明 / 镂空区域。

> ⚠️ 除了「原生 co」，没有别的透明路线。旧教程里的自建镂空 / 半透明选项已经删掉，旧工程里残留的这类值导出时会被当**不透明**处理。

## 8.2 原生 co 的前提

- 你的配置档必须来自**包含透明部件的抓帧**（不是每套服装都有透明件）；
- 配置档里没有透明部件时，导出会报错——把材质槽改回「不透明」，或换一个含透明件的抓帧重新生成配置档（见 [[4-步骤①-准备配置档]]）。

## 8.3 co 有自己独立的贴图

勾选原生 co 后：

- 必须在 **「co 基础色 t0 / m_bdyco」** 填单独贴图——它用透明材质自己的 t0/UV，**不会回退或借用** body 的 t0；
- co 的 `t1/t4` 也有独立字段；留空时生成 co 专属中性图，**不共用** body 的 t1/t4。

| Blender 路径 | 要求 |
|---|---|
| `co 基础色 t0 / m_bdyco` | 透明 / 镂空部件自己的 RGBA；A 用于镂空，**透明区 RGB 要外扩**（见 [[9-常见问题与排错]] 透明变黑） |
| `co 混合遮罩 t1` | co 部件自己的 PackedMask，不共用 body t1 |
| `co 暗面材质 t4/sdw` | co 部件自己的暗面图，不共用 body t4 |

没选「原生 co」时这三项必须留空。

> **只有你自己标了「原生 co」的槽才需要这三张图。**目标服装原版有几个材质段（有的服装是 3 段）
> 跟你要不要做 co 无关——你没用到的段会保留原版材质。插件 0.9.3 之前会按目标段数硬要 co 的
> t0，导致普通不透明工程也报「材质槽 1 缺少 t0 基础色贴图」，升级即可。

## 8.4 co 是 cutout，不是真半透明

原生 co 实测是**"要么透、要么不透"**：alpha 低于某个门槛的地方直接被抠掉，高于门槛的地方正常显示；**中间的半透明度不会平滑过渡**。所以适合镂空、网眼、边缘裁剪；薄纱 / 玻璃那种连续半透明目前做不了。

## 8.5 实机测试步骤

1. 用包含透明部件的抓帧生成完整配置档；
2. 导入作者模型并对齐后，在材质列表把需要透明的材质槽设为 **原生 co**；
3. 在「不透明 body / m_bdy」填 body 的 t0/t1/t4；只要有任一槽设为原生 co，还必须在「原生 co / m_bdyco」填 co 的 t0（有 co 的 t1/t4 也填这里）。body 与 co 各走各自 UV、尺寸和贴图，互不干涉；
4. 点 `导出并打包 bundle（一键，需外部 Python）`，把整个 `<模组标识>\` 目录放进
   `<游戏目录>\gakumas-mod\mods\`；
5. 进游戏在 **Mod 管理**页打开开关，观察：透明 / 镂空是否正常、有无残留或亮度叠加。
   不正常时保留 `bundle-src\` 与 runtime 的 `gakumas-mod\mod-plugin.log` 用于排查。
