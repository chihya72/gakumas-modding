# 5. 步骤②：材质与贴图

这一步给替换后的网格准备贴图。**这里填的路径是你自己制作的 PNG/DDS，不是 `FrameAnalysis` 里的原始槽位文件。**

发型 / 发饰的贴图语义与 body 不同，见 [[7-发型与发饰]]；透明件见 [[8-透明材质（原生co）]]。

## 5.1 三张主贴图

每个被替换组件都按同一套主槽位填：

| Blender 字段 | 游戏槽位 | 作用 | 必填 |
|---|---|---|---|
| 基础色 t0 | `ps-t0` | 角色最终显示的基础颜色 | ✅ 是 |
| 混合遮罩 t1 | `ps-t1` | 阴影阈值 / 光滑度 / 金属度 / 门控 | 可选 |
| 暗面材质 t4/sdw | `ps-t4` | 卡通暗面使用的颜色与材质分支 | 可选 |

规则：

- PNG 可直接填（导出时自动转 DDS），已有 DDS 也可直接填；
- **三张图必须是正方形**，同一组件的 t0/t1/t4 用**同一 UV 布局和尺寸**；
- **t1 是线性数据，不能套 sRGB**；t0/t4 是颜色数据；
- 只有 t0 时，勾「中性 t1/t4」或点「按材质生成 t1/t4 并校准肤色」——**不要让插件沿用目标角色原来的 t1/t4**，否则新 UV 会采到旧衣服的颜色块。

推荐目录：

```text
MyMod/textures/
  body_t0.png  body_t1.png  body_t4.png
  hair_t0.png  hair_t1.png  hair_t4.png
  hairprop_t0.png ...
```

> 📷 **待截图**：`images/step3-slots.png` —— 步骤②「材质槽设置」区，标出 t0/t1/t4 三个字段。

## 5.2 t1 是 PackedMask，四个通道各管一件事

| 通道 | 作用 | 常见作者输入 |
|---|---|---|
| **R** | 卡通阴影阈值 / 进暗面范围（越低暗面越大） | toon mask / shadow threshold |
| **G** | 光滑度 | smoothness / roughness 转换图 |
| **B** | 金属度 | metallic 图 |
| **A** | 镜面 / 间接光可见性门控（body 常按 AO 用） | AO / 材质可见性图 |

## 5.3 t4 是暗面材质，不是投影阴影

`t4.rgb` **不是**动态投影阴影贴图，而是角色进入卡通暗面时采样的**材质颜色**。它应该和 t0 **同 UV、同图案，只是更暗或轻微偏色**。

> ⚠️ 只换 t0 不换 t4 → 暗面会继续读原服装的 `sdw`，出现不属于当前衣服的彩色图案。这是最常见的暗面 bug。

## 5.4 按材质生成 t1/t4 并校准肤色（推荐给外部模型）

自定义 atlas（MMD 等自带 UV、无游戏 t1/t4 来源）用这个，比平铺「中性」更接近原作。预设数值由实机抓帧逐材质实测，存于 `material_presets.json`。

**用法：**

1. 在 Blender 给模型分材质（披风 / 制服 / 皮肤 / 皮鞋…各一个材质槽）；
2. 填好「基础色 t0」（PNG）；
3. 在「分材质烘焙」区给每个材质选**材质类型**，需要时只调每行的 **明暗**；
4. 有外部阴影阈值 / 粗糙度图，可在「t1 通道输入」只填对应通道；
5. 点 **`按材质生成 t1/t4 并校准肤色`** → 自动写成同尺寸 DDS 并设为导出 t1/t4 → 正常校验导出。
   开着「肤色对齐原版」（默认）时还会另存一份校准过的 t0 并回填到「基础色 t0」栏，
   把标为**皮肤**的区域对齐到原版身体肤色 `(254, 230, 218)`——脸和头发是原版贴图，
   不对齐脖子上会有色差断层。你的原文件不会被改。

材质类型预设（归一化 0–1）：

| 类型 | 明暗阈值 | 光滑度 | 金属度 | t1.A | t4.A | 适用 |
|---|---|---|---|---|---|---|
| 皮肤 | 0.45 | 0.13 | 0 | 0 | 1 | 裸露皮肤 |
| 布料 | 0.38 | 0.40 | 0 | 0 | 0 | 制服 / 衬衫 / 针织袜 |
| 皮鞋 / 哑光皮革 | 0.42 | 0.38 | 0 | 0.10 | 0 | 皮鞋 |
| 皮革 / 塑料(亮面) | 0.50 | 0.70 | 0 | 0.54 | 0 | 漆皮 / 塑料件 |
| 金属 | 0.34 | 0.73 | 0.75 | 0.57 | 0 | 金属扣 / 饰品 |
| 头发 | 0.263 | 0.125 | 0 | 0 | 0 | 发丝（见 [[7-发型与发饰]]） |
| 中性 | 1.0 | 0 | 0 | 1.0 | 0 | 等价旧「中性」 |

每个材质行只有一个手动微调 **明暗**（-1 = 用预设）：越低阴影越大越暗、越高受光越多越亮。**t4.A 不提供手动选项**，由材质类型固定写二值结果（皮肤通常 255、非皮肤通常 0）；它不是透明度。

## 5.5 面板上还有这几个开关

除了三张图和材质类型，步骤②面板里还有：

| 控件 | 在哪 | 做什么 |
|---|---|---|
| **渲染材质**（不透明 / 原生co） | 每个材质槽一份 | 该槽走普通身体路径，还是交给游戏原生 `m_bdyco` 画镂空。判据是**该贴图实际 UV 足迹里透明像素多不多**，不是"看起来像纱"。见 [[8-透明材质（原生co）]] |
| **明暗(阴影范围)** | 每个材质槽一份 | `-1` = 用该材质类型的预设。调低阴影铺得更大更暗，调高受光更多。**只影响这一个槽**，暗场景发乌的小件可以单独提亮 |
| **中性 t1/t4** | 全局 | 只想先看颜色对不对时勾它，跳过按材质生成 |
| **几何AO软化阴影** + **软化强度** | 全局 | 从网格几何烘 AO，只加深凹陷缝隙（腋下 / 裆部 / 衣褶内）。默认关 |
| **创建预览材质模板** | 按钮 | 在 Blender 视口里近似预览游戏材质，不影响导出，纯粹用来自查 |

> `co 基础色 t0 / m_bdyco` 那三栏**只在有材质槽标了「原生co」时才必填**，它用自己的贴图和 UV，
> 不共用身体那套。

## 5.6 t1 单通道输入（只有某一路图时）

只给某个 t1 通道一张图：

| Blender 字段 | 写入通道 | 适用 |
|---|---|---|
| `t1.R 阴影阈值` | R | 有独立 toon / shadow mask |
| `t1.G 光滑度` | G | 有 smoothness / roughness 图 |
| `t1.B 金属度` | B | 有 metallic 图 |
| `t1.A AO` | A | 明确知道 AO / 间接光门控位置 |

- **只填部分通道**：插件先按材质预设生成完整 t1，再只覆盖有内容的材质区域（空白黑区不覆盖）；
- **四个通道都填**：插件视为完整 PackedMask，整图合成。

推荐外部服装流程：t0 填 atlas → 只把阴影阈值图填到 `t1.R`、其余留空 → 选材质类型 + 「不透明 / 原生 co」→ 点生成。暗面范围不对时先调 `t1.R` 的黑白点或材质行「明暗」，**别把 Rmask 直接塞满 G/B/A**。

## 5.7 不需要作者准备的槽位

| 槽位 | 由谁提供 |
|---|---|
| `t2` | 全局环境立方图，游戏场景提供 |
| `t3` | 动态阴影深度图，游戏实时生成 |
| `t5` | Ramp，目标 shader / 材质提供 |
| `t6` | 发丝高光图，当前主流程不替换 |
| `t7` | RampAdd，目标材质提供 |

## 5.8 导出前最小检查表

- [ ] Body 至少有 `t0`；不想用旧材质就启用中性 t1/t4 或按材质生成；
- [ ] 同一组件三张图尺寸、UV、上下方向一致；
- [ ] t1 是线性、不套 sRGB；
- [ ] 不要把 t4 当动态阴影图，也不要把 t0.A 当普通透明度；
- [ ] 每次「按材质生成 t1/t4 并校准肤色」后确认激活的是正确组件网格；
- [ ] 路径指向你自己的 PNG/DDS，不是 `FrameAnalysis` 里的原始文件。
