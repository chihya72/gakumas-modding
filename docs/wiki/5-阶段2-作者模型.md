# 5. 阶段 2：作者模型

这一阶段把“场景里当前碰巧选中了什么”变成“后续固定使用哪个网格”。材质、骨架、体检和导出都围绕这里确认的作者模型工作。

## 5.1 选择方式

有两种等价入口：

- 在 `作者模型` 字段直接选择一个 Mesh 对象；
- 先在 3D 视图激活一个非参考 Mesh，再点击主按钮。插件会把它写回 `作者模型`。

点击 `确认并使用这个作者模型` 后，该对象会被激活，并进入阶段 3。

制作 hair 时，顶层 `作者模型` 必须选 Geo_Hair 对应的发型网格；需要同时替换发饰时，另在 `配套发饰（可选）` 选择 Geo_HairProp 网格。不要反过来把发饰当主作者模型。

## 5.2 插件会检查的项目

| 红色提示 | 实际要求 |
|---|---|
| 没有顶点组 | 作者模型必须先绑定并拥有权重 |
| 没有活动 UV0 | 至少有一个活动 UV；应把最终图集 UV 设为活动层 |
| 没有有效材质槽 | 至少一个材质槽要指向真实 Blender 材质 |
| 没有 Armature 修改器 | 网格必须仍绑定到作者骨架对象 |
| 对象缩放尚未应用 | 确认尺寸后执行 `Ctrl+A > 缩放` |
| 对象旋转尚未应用 | 确认朝向后执行 `Ctrl+A > 旋转` |

字段中的“活动 UV0”指用于导出的活动 UV 层。最稳妥的做法是只保留最终图集 UV，并命名为 `UV0`。

## 5.3 插件不会替你判断的项目

下列问题不会因为本阶段没有红字就自动正确：

- 作者模型与参考骨架是否真正重合；
- 是否处于正确 T-pose；
- body 项目是否删干净原模型的头发、脸、口腔和被衣服完全遮住的内层；
- 法线、重复面、孤立点、非流形和穿模是否处理完；
- 权重是否绑定到正确关节，动作时是否撕裂；
- 多个材质是否已经整理到可导出的共同图集。

因此按钮可用只表示数据结构齐全，不表示模型已经通过视觉验收。

## 5.4 推荐的准备顺序

1. 保留一份未处理源文件。
2. 用阶段 1 导入的原版网格和骨架作为只读参照。
3. 完成删头、内层清理、镜像和重复面处理。
4. 整理正方形图集与 UV。
5. 对齐全身骨架，而不是只对手臂或脚底。
6. 在 Blender 中测试肩、肘、腕、髋、膝和手指动作。
7. 确认对象尺寸和朝向后应用旋转、缩放。
8. 再回本页确认作者模型。

外部模型的完整整理顺序见 [[外部模型转换|12-外部模型转换]]。

## 5.5 多网格和多材质

主作者模型是一个 Mesh 对象。若源模型由多个物件组成，正常路线是在进入本阶段前合并为最终网格，同时保留合理材质槽。

多个材质槽可以存在，但阶段 3 和最终导出都假设它们已经共享同一套图集。插件可以把材质段归并到目标 body 或 hair 的段数，不能替作者把多张互不相关的贴图自动烘成一张 atlas。

完成后进入 [[阶段 3：材质与贴图|6-阶段3-材质与贴图]]。
