# 3. 快速上手：第一个换装 mod

这一页用最短路径带你做一个 **body 换装 mod**（换身体 / 服装）。发型见 [[7-发型与发饰]]，透明件见 [[8-透明材质（原生co）]]。

> 前置：已完成 [[1-环境准备与安装]]（插件能打开、有资源库、有一个抓帧目录）。
>
> **还有一条前置在你自己身上**：作者模型必须已经**对齐好、删好头、自带有效权重**。插件不做建模对齐、不刷权重、不修 UV，它负责的是对齐之后的一键导出。
>
> 从外部模型（MMD/PMX 等）做起的，先看 [[10-外部模型转换实战规范]] —— 镜像判定、图集打包、全骨架 retarget 都在那里。

## 一图流程

```
1 目标与参照 ──→ 2 指定作者模型 ──→ 3 生成材质贴图
                                           │
                                           ▼
                     5 集中检查并导出 ←── 4 处理骨架与物理
                              │
                              ▼
   .bundle + mod.json 放进 gakumas-mod\mods\<模组标识>\
```

> 📷 **待截图**：`images/quickstart-overview.png` —— 面板顶部五阶段导航和各阶段主按钮的拼图。

## 阶段 1：目标与参照

1. 顶部选择制作目标 `身体（body）`，阶段选 **1 目标**，目标来源保持 `从抓帧新建`；
2. 填 `抓帧目录`（你的 `FrameAnalysis-*`）；
3. 填 `身体 JSON 资源库`（body 库，含 `Geo_Body`）；
4. 点唯一的大按钮 **`生成配置档并导入目标参照`**。

参考身体是**对照物**：把你的模型摆到它的位置、同 T-pose、接近尺寸，然后 `Ctrl+A` 应用缩放 / 旋转。细节 / 排错见 [[4-步骤①-准备配置档]]。

> 📷 **待截图**：`images/step1-generate.png` —— 阶段 1 的目标来源、两个必填路径和主按钮。

## 阶段 2：指定作者模型

1. 切到 **2 模型**；
2. 在 `作者模型` 里选要导出的网格；也可以先在 3D 视图激活网格，再点主按钮采用它；
3. 对照页面清单处理红色问题：活动 UV0、有效材质槽、Armature 修改器、顶点权重，以及已经应用的旋转和缩放；
4. 点 **`确认并使用这个作者模型`**。

后续材质、骨架、体检和导出都固定使用这个对象，不需要在每次操作前重新猜哪个网格应当激活。

## 阶段 3：材质与贴图

最省事的起步：

1. 切到 **3 材质**，`基础色 t0` 填你的 PNG（正方形，插件导出时自动转 DDS）；
2. 在材质列表选中一个槽，在下方详情里标好材质类型（皮肤 / 布料 / 金属等）和渲染方式；
3. 逐槽确认后点 **`生成游戏材质贴图`**；
4. **不要**让插件沿用目标角色原来的 t1/t4，否则新 UV 会采到旧衣服的颜色块。

> **肤色对齐**默认开着：脸和头发用的是原版贴图，身体是你的，不对齐脖子上会有一道明显色差断层。插件会把标为「皮肤」的区域整体缩放到原版肤色，校准后的 t0 另存并回填，**不改你的原文件**。

材质类型、单通道输入、暗面 t4 语义等进阶内容见 [[5-步骤②-材质与贴图]]。

## 阶段 4：骨架与物理

1. 切到 **4 骨架**，点 **`扫描源骨骼`**建立待处理队列；
2. 在队列选中一组骨，在下方详情里决定它怎么处理：
   - MMD / Mixamo / Rigify / SCSP 等八家常见命名会自动预填，队列主要留下无法自动决定的组；
   - 身体骨在 `映射到游戏骨` 中打字搜索并选择；
   - 装饰骨选择处理方式：裙边要精确同步可用**「跟裙摆」**；独立飘带/蝴蝶结可用
     **「自建摇物链」**（`hmsz-fuyuko-icu` 已画面级验证）；硬件用「刚性跟父骨」。见
     [[9-常见问题与排错]] 9.10。
3. 有很多红色项时打开 `只看这些`；处理完后点 **`量对齐与跨关节权重带`**。

## 阶段 5：检查与导出

1. 切到 **5 导出**；
2. 填模组信息、输出目录和与目标资源对应的 `R32 模板 bundle`；
3. 查看集中预检。红色项会说明应返回哪个阶段处理，全部清零后主按钮才会启用；
4. 点 **`导出并打包 bundle`**。

**导出前有一道硬闸门**：21 个承重关节任一没拿到权重，插件会**拒绝导出并点名是哪根**。触发了就回映射表把那根源骨指对。

导出得到 `.bundle` + `mod.json`，放进：

```text
<游戏目录>\gakumas-mod\mods\<你的模组标识>\
```

进游戏，在**游戏内 Mod 管理**页面打开开关。细节见 [[6-步骤③-导出AB bundle]]。

> 装的是 chinosk6 的 `gkms-localify-dmm` 而不是 Mod Runtime 的话，目录是它自己的
> `<游戏目录>\gakumas-local\local-files\mods\<你的模组标识>\`，也没有游戏内管理页。

## 第一个 mod 常见翻车点

| 现象 | 大概率原因 | 去哪看 |
|---|---|---|
| 阶段 5 仍有骨组待处理 | 阶段 4 的队列里还有未决定、拒绝或无效的装饰骨策略 | [[6-步骤③-导出AB bundle]] |
| 导出被拒，提示某个承重关节没权重 | 该源骨没映射到游戏骨，或模型那块本来就没刷权重 | [[6-步骤③-导出AB bundle]] |
| 进游戏模型错位 / 沉到地下 | 作者模型没和参考身体对齐，或没 `Ctrl+A` | [[4-步骤①-准备配置档]] |
| 换模后**没有描边** | 新网格缺顶点 COLOR | [[9-常见问题与排错]] |
| 脖子上一道色差断层 | 关掉了「肤色对齐原版」，或材质类型没标成「皮肤」 | [[5-步骤②-材质与贴图]] |
| 暗面出现不属于这件衣服的图案 | 只换 t0 没换 t4 | [[5-步骤②-材质与贴图]] |
| 飘带 / 裙摆不动或乱甩 | 装饰骨策略选错 | [[2-核心概念]] |

跑通一个 body mod 后，再看专题页拓展到发型和透明件。
