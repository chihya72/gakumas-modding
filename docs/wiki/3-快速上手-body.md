# 3. 快速上手：第一个 body Mod

本页只走最短可交付路径。它假设作者模型已经删去不需要导出的头部和内部面，拥有一套正方形图集，并且已经绑定到自己的骨架。

如果这些条件尚未满足，先看 [[外部模型转换|12-外部模型转换]]。

## 3.1 阶段 1：准备目标

1. `当前制作目标` 选择 `身体`。
2. `目标来源` 选择 `从抓帧新建`。
3. `抓帧目录` 选择目标服装的 `FrameAnalysis-*`。
4. `身体 JSON 资源库` 选择 `assetstudio-body-json`。
5. 自动匹配有歧义时，在 `目标 body 资源（可选）` 填完整目标资源名。
6. 点击 `生成配置档并导入目标参照`。

完成后场景里应出现原版参考网格和骨架。详细说明见 [[阶段 1：目标与参照|4-阶段1-目标与参照]]。

## 3.2 阶段 2：确定作者模型

1. 把作者网格摆到参考模型相同的位置、T-pose 和大致尺寸。
2. 确认作者网格仍有 Armature 修改器和顶点权重。
3. 把导出图集所在的 UV 设为活动 UV。
4. 执行 `Ctrl+A > 旋转` 与 `Ctrl+A > 缩放`。
5. 在 `作者模型` 选择该网格。
6. 点击 `确认并使用这个作者模型`。

红色问题没有清空前不要进入下一阶段。插件只能检查数据是否存在，不能判断姿势、造型和权重质量。详细说明见 [[阶段 2：作者模型|5-阶段2-作者模型]]。

## 3.3 阶段 3：生成游戏材质

1. `基础色 t0` 选择作者模型的正方形基础色图。
2. 在材质槽列表逐个选择材质，把 `材质类型` 设为皮肤、布料、金属等真实用途。
3. 第一版全部使用 `不透明`。确实需要镂空或半透明时再看 [[透明材质|10-透明材质]]。
4. 没有自制 t1、t4 时保持 `中性 t1/t4` 开启。
5. 皮肤区域需要与原版头部接色时保持 `肤色对齐原版` 开启。
6. 点击 `生成游戏材质贴图`。
7. `描边颜色` 首先使用 `取自基础色`，`描边宽度` 使用 `正常描边`。

插件会另存生成结果并更新路径，不修改原始 t0。详细说明见 [[阶段 3：材质与贴图|6-阶段3-材质与贴图]]。

## 3.4 阶段 4：处理骨架

1. 点击 `扫描源骨骼`。
2. 预设能确定的常见身体骨不会占据待处理列表；列表主要显示无法自动决定的骨组。
3. 身体骨在 `映射到游戏骨` 中选择目标。
4. 硬质附件选 `刚性跟父骨`；裙边可选 `跟裙摆`；需要独立运动的链再考虑 `自建摇物链`。
5. 每个红色骨组都必须处理。需要逐根不同处理时点击 `拆成逐根处理`。
6. 点击 `量对齐与跨关节权重带`，阅读只读体检结果。

如果导出时提示关键关节没有权重，源骨存在就补映射；源模型根本没有该关节时，才使用折叠区中的 `从相邻骨劈权重`。详细说明见 [[阶段 4：骨架与物理|7-阶段4-骨架与物理]]。

## 3.5 阶段 5：导出

1. 填写唯一的 `模组标识`，例如 `author.hski.my-costume`。
2. 填写显示用的 `模组名称` 和 `作者`。
3. `输出目录` 选择一个可写目录。
4. `R32 模板 bundle` 选择与阶段 1 目标资源同名的模板。
5. 当前公开插件包会显示 `外部 Python`；确认它能导入 `UnityPy==1.10.18` 与 Pillow。
6. 按红色提示返回对应阶段修正，直到按钮可用。
7. 点击 `导出并打包 bundle`。

成品位置：

```text
<输出目录>\<mod-id>\
  <mod-id>.bundle
  mod.json
  bundle-src\
```

把整个 `<mod-id>` 目录复制到：

```text
<游戏目录>\gakumas-mod\mods\
```

重启游戏，在游戏内 `Mod 管理` 页面启用。详细说明见 [[阶段 5：检查与导出|8-阶段5-检查与导出]]。

## 3.6 第一次实机验收

不要只看静止正面。至少检查：

- 正面、背面和侧面是否错位或露出未删除面；
- 行走和转身时肩、肘、腕、髋、膝是否撕裂；
- 皮肤与原版头部是否有明显色差；
- 暗面是否出现原服装图案；
- 描边是否存在，裙内侧是否出现粗黑线；
- 装饰链是否不动、甩飞或穿模。

出现问题时按现象查 [[常见问题与排错|11-常见问题与排错]]。
