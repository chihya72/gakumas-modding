# 1. 安装与资源

完成本页后，你应当能在 Blender 里打开 GakumasMI 面板，并准备好一次抓帧、一个原版 JSON 资源库、模板目录和游戏运行时。

## 1.1 需要哪些东西

| 项目 | 用途 | 何时需要 |
|---|---|---|
| Blender 4.2 LTS 或 4.5 LTS | 运行作者插件 | 始终 |
| Gakumas Mod 制作工具发布包 | 提供 GakumasMI 插件和抓帧环境 | 始终 |
| 原版 JSON 资源库 | 导入带权重的目标参考网格和骨架 | 阶段 1 |
| 模板目录（`templates`） | 把作者数据打进 AssetBundle；用哪个模板由插件按目标资源名自己找 | 阶段 5 |
| 外部 Python 3.10 或更高 | 当前公开插件包没有内置 UnityPy，负责最后打包 | 阶段 5 |
| Gakumas Mod Runtime | 在游戏里读取 Mod 并提供管理页面 | 实机使用 |

不需要安装 Unity。3DMigoto 只在阶段 1 抓一帧，成品不是 3DMigoto Mod。

## 1.2 下载

从 [gakumas-modding Releases](https://github.com/chihya72/gakumas-modding/releases) 下载当前制作工具包。解压后：

- `blender-addon\gakumas_mi-<版本>.zip` 是 Blender 插件，不要先解压；
- `3dmigoto_gkms\` 是抓帧环境；
- `安装说明.txt` 是发布包内的简版安装说明。

成品 Mod 由独立的 [Gakumas Mod Runtime](https://github.com/chihya72/gakumas-mod-runtime/releases) 加载。把 Runtime 发布包解压到 `gakumas.exe` 所在的游戏根目录。

原版 JSON 与模板体积较大，不放在 Git 仓库中。素材包地址：

- [百度网盘](https://pan.baidu.com/s/1gQCJASpR42gLvmcEfsRj-Q)，提取码 `es08`。

素材包的 `libraries` 目录包含：

```text
libraries\
  assetstudio-body-json\
  assetstudio-hair-json\
  templates\
```

只做 body 时需要 body JSON 库，只做 hair 时需要 hair JSON 库；两者都用同一个 `templates` 目录。

阶段 5 只要把 `templates` 整个目录填进去就行——具体用哪个模板由插件按配置档里的目标资源名自己找，你不需要知道抓到的那套衣服是什么编号。

## 1.3 安装 Blender 插件

在 Blender 中打开：

```text
编辑 > 偏好设置 > 插件 > 从磁盘安装
```

选择 `gakumas_mi-<版本>.zip` 并启用 GakumasMI。面板位置：

```text
3D 视图 > 右侧边栏（N）> GakumasMI
```

面板标题应显示当前版本，顶部应有 `1 目标` 到 `5 导出` 五个阶段。如果仍是旧按钮或旧布局，先卸载旧插件，关闭 Blender，重新打开后再安装新版 ZIP。

## 1.4 配置打包用 Python

当前公开的 GakumasMI 插件 ZIP 是轻量包，不含 `vendor\UnityPy`。因此阶段 5 会显示 `外部 Python`，它必须指向一个独立安装的 Python，不能指向 Blender 自带 Python。

推荐 Python 3.11 或 3.12。安装后执行：

```powershell
python -m pip install UnityPy==1.10.18 Pillow
python -c "import UnityPy, PIL, sys; print(sys.executable)"
```

第二条命令应打印实际的 `python.exe` 路径。若 `外部 Python` 保持默认值 `python` 时找不到程序，就把该绝对路径填入面板。`WindowsApps\python.exe` 可能只是 Microsoft Store 占位程序，不应作为打包器。

必须固定 `UnityPy==1.10.18`：当前补丁脚本按 1.10.x API 编写，直接安装不兼容的新版本可能在最后一步失败。

以后如果发布包内含 `gakumas_mi\vendor\UnityPy` 与 `PIL`，插件会优先使用内置依赖，并隐藏 `外部 Python`；是否显示该字段就是当前安装实际走哪条路径的判据。

## 1.5 准备一次抓帧

把 `3dmigoto_gkms\` 中的文件复制到游戏根目录。若那里已有你自己的 `d3dx.ini`，先备份并确认配置，不要直接覆盖。

使用 `-force-d3d11` 启动游戏，让目标角色穿上准备替换的服装或发型，按 F8。成功后游戏目录会出现：

```text
FrameAnalysis-<日期时间>\
```

阶段 1 的 `抓帧目录` 就选择这个文件夹。抓帧环境只负责生成目标识别资料，不负责加载最后的 `.bundle`。

## 1.6 安装位置与检查清单

Runtime 解压正确时，游戏根目录至少应有：

```text
xinput1_3.dll
gakumas-mod\
  config.json
  mods\
```

每个成品 Mod 放在自己的目录：

```text
<游戏目录>\gakumas-mod\mods\<mod-id>\
  mod.json
  <mod-id>.bundle
```

开始制作前确认：

- Blender 面板显示 GakumasMI 版本号和五个阶段；
- 有一个目标明确的 `FrameAnalysis-*` 目录；
- body 或 hair JSON 资源库中能看到按资源名分组的目录；
- 有一个装着 `template_*.bundle` 的 `templates` 目录；
- 外部 Python 能导入固定版本的 UnityPy 和 Pillow；
- 游戏端 Runtime 已单独安装。

准备完成后看 [[插件负责什么|2-插件负责什么]]，或直接按 [[body 快速上手|3-快速上手-body]] 操作。
