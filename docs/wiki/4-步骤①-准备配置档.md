# 4. 阶段 1：目标与参照

配置档是插件认识游戏对象的“说明书”（见 [[2-核心概念]]）。做任何 mod 都从这里开始。
阶段 1 只要求选择目标来源，再完成一个主操作。

## 4.1 第一次替换这个目标：从抓帧新建

- `目标来源` 选择 **`从抓帧新建`**；
- 填 `抓帧目录`（`FrameAnalysis-*`）；
- 填对应的 `身体/发型 JSON 资源库`（body 库含 `Geo_Body`；发型库含 `Geo_Hair` 与 `Geo_HairProp`）；
- 必要时填写目标 body/hair 资源提示；
- 点 **`生成配置档并导入目标参照`**。

这个按钮会连续完成配置档生成与参照导入。跑完后 `配置档目录` 自动指向新生成的那一档，
后续四个阶段都围绕它工作。

> 📷 **待截图**：`images/step1-inputs.png` —— 阶段 1 的来源选择、两个必填路径、主按钮和高级折叠区。

插件会自动扫描抓帧、从资源库匹配到对应的原版身体、把 Mesh 与骨架结构收进配置档，产出一个**可以直接用的完整配置档**。完成后 `配置档目录` 自动指向新配置档。

导入的参考身体是**对照物**，不是权重来源：把你的模型摆到它的位置、同 T-pose、接近尺寸，然后 `Ctrl+A` 应用缩放 / 旋转。**权重用你自己模型上的，插件不传权**（见 [[2-核心概念]]）。

## 4.2 已经做过这个目标：复用配置档

- `目标来源` 选择 **`使用已有配置档`**；
- 填 `配置档目录`；
- 点 **`导入目标参照`**。

配置档可以长期复用；换作者模型或贴图不需要重新抓帧。游戏更新、抓帧变化或目标资源发生变化时，
再到高级区执行校验更新。

配置档与参照就绪后进入 [[阶段 2–3：作者模型、材质与贴图|5-步骤②-材质与贴图]]。

## 4.3 同一件衣服有多套时会怎样

同一基础身体、只是贴图不同的多套服装，插件会自动判定为等价、任取其一，不用你选。只有极少数情况下插件拿不准（匹配到多个不一致的候选），才会提示你手动指定具体 Body。

## 4.4 出问题时：高级 / 分步 / 排错

主流程失败时展开 `高级 / 分步` 折叠区，逐步定位：

| 按钮 | 作用 |
|---|---|
| `仅生成注入信息（不补权重骨架）` | 只做第一步：从抓帧识别游戏对象 |
| `仅匹配资源库（查匹配结果）` | 只做资源库匹配，看它找到的是哪套原版身体 |
| `换新抓帧校验并更新配置档` | 游戏更新或换了抓帧后，检查现有配置档还对不对 |
| `导入配置档全部对象（排错）` | 把配置档里的东西全导进来看 |
| `只导入抓帧参考模型（无权重）` | 只要抓帧里那个网格，不带骨架权重 |

同一折叠区里还有两个框：**`新配置档输出`**（生成的配置档写到哪，留空用默认位置）和**`主 Draw`**（自动选错对象时，填 3DMigoto 左上角显示的 Draw 编号强制指定，`0` = 自动）。

## 4.5 命令行生成（可选）

不想开 Blender 也能生成配置档：

```powershell
python tools\extract_frame_profile.py <FrameAnalysis目录> profiles\generated-body --component body
```

**自动选错了对象时**，按 3DMigoto 顶部显示的 Draw 编号强制指定：

```powershell
python tools\extract_frame_profile.py <FrameAnalysis目录> <输出目录> --component body --draw 335
```
