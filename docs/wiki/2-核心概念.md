# 2. 你会反复遇到的几个词

这页是术语速查。不用背，做 mod 时遇到哪个回来查哪个。只讲"对你有什么影响"，不讲引擎内部怎么实现。

## 配置档（Profile）

**插件认识一个游戏对象的"说明书"。** 它记录了你要替换的是哪个角色 / 服装 / 组件（例如 `hski / cstm-0000 / body`），以及导出时该按什么格式打包。

对你的影响：**做任何 mod 第一步永远是准备配置档**（[[4-步骤①-准备配置档]]），否则插件不知道你要替换谁。大多数情况你只要点一下「生成完整配置档」，不用管里面记了什么。

## 抓帧目录（FrameAnalysis-\*）

3DMigoto 从运行的游戏里"截"下来的一帧数据。插件靠它认出你要替换的对象在游戏里长什么样、用了哪些贴图槽。

对你的影响：**生成配置档时要填这个目录**。你只需要有一个抓到目标角色 / 服装的抓帧文件夹即可。

## 网格 JSON 资源库

AssetStudio 从游戏缓存离线导出的原模型数据（一次性准备，见 [[1-环境准备与安装]]）。插件用它给你的作者模型提供"带权重的参考身体"。

对你的影响：**生成配置档时要填这个库的路径**。500+ 套服装都在里面，插件自动匹配，你不用手动找。

## 组件（Component）

一个 mod 可能要换好几个部件，各自一套流程：

- **body** —— 身体 / 服装主体；
- **hair** —— 发型网格；
- **hairprop** —— 配套发饰，跟发型一起（见 [[7-发型与发饰]]）。

## 参考模型 / 参考身体

插件从资源库导进来的**带骨骼权重的原版身体**。它现在的作用是**对照物**：让你把作者模型摆到正确的位置、姿势和尺寸，并作为骨名的来源。

对你的影响：

- 你的作者模型仍然要**摆到参考身体同一位置、同一 T-pose、同样大小**——不是为了传权重，而是因为游戏骨架就在那个空间里，位置对不上进游戏就会错位；
- **权重不从参考身体借。**见下条。

## 骨骼映射（替代了旧的"转权"）

**0.9.0 起插件不再传递权重。**你的模型自带的权重原样保留，插件只做一件事：把**你的骨名**换成**游戏的骨名**，然后把网格作为 Unity 资产打包，由游戏引擎自己蒙皮。

对你的影响：

- 作者模型**必须自带有效权重和骨架**——插件不会帮你刷权重；
- 骨名认得出来（MMD / Mixamo / Rigify / VRM / 3ds Max Biped / Auto-Rig Pro / SCSP / 英文 Humanoid 八家预设）就自动预填；认不出来去步骤③的**骨骼映射表**逐行点选；
- 导出前插件会查 **14 个承重关节**（Hips / Spine / 左右 Arm-ForeArm-Hand-UpLeg-Leg-Foot）有没有拿到权重，缺任一根**拒绝导出并点名**——防止"导出成功、进游戏才发现整只手钉在 Spine1"。

## 装饰骨物理策略

飘带、蝴蝶结、裙边花边这类骨头，**名字和位置都决定不了它该怎么动**。插件默认给一个不会炸的策略（刚性跟父骨），你可以在骨骼映射表第二列逐条改成「自建摇物链」「跟裙摆」「跟指定骨」。

## 三张主贴图：t0 / t1 / t4

每个被替换的组件都按同一套槽位填贴图（详见 [[5-步骤②-材质与贴图]]）：

| 字段 | 作用 | 一句话 |
|---|---|---|
| **t0** 基础色 | 角色最终显示的颜色 | 必填，就是你画的贴图 |
| **t1** 混合遮罩 | 阴影 / 光滑 / 金属 / 门控 | 没有就让插件"按材质生成" |
| **t4** 暗面材质 | 进暗面时显示的颜色 | 和 t0 同图案、只是更暗；**不是投影阴影** |

准备好这几个词的印象，就可以开工了 → [[3-快速上手：第一个换装 mod]]。
