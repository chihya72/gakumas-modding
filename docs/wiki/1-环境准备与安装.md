# 1. 环境准备与安装

本页帮你在 Blender 侧装好插件、准备好资源库，跑通"能打开面板"这一步。

你还需要**抓帧环境**（`3dmigoto_gkms` 抓帧包）来按 F8 抓一帧做配置档——它只抓帧，不加载 mod。
玩家侧运行环境（`xinput1_3.dll` Mod Runtime，游戏内管理 UI 已内含其中）不在本 wiki 范围内，见对应仓库 README。

## 1.1 你需要准备什么

| 组件 | 说明 | 必需 |
|---|---|---|
| **Blender 4.2 LTS** | 插件宿主（4.5 LTS 也有 CI 覆盖） | 是 |
| **GakumasMI 插件 ZIP** | 本项目构建产物 | 是 |
| **Python 3.10+**（**独立装，不是 Blender 自带的**） | 最后打包 bundle 那一步要用，见 1.4 | 是（导出成品要） |
| **网格 JSON 资源库** | 原模型 / 骨架 JSON，约数 GB。**百度网盘提供现成的**，不用自己导 | 是（换 body / hair 都要） |
| **Unity 模板 bundle（R32 模板）** | 打包时被 UnityPy 打补丁的空壳 AB。**百度网盘提供现成的**，工具作者一次性批量产 | 是（打成品包要） |
| **抓帧目录（FrameAnalysis-\*）** | 用抓帧环境按 F8 抓的一帧 | 生成配置档时要 |
| **3dmigoto_gkms 抓帧包** | 只抓帧、不加载 mod | 抓帧时要 |

**不需要装 Unity。**打包走的是「UnityPy 给**现成的 Unity 模板 bundle** 打补丁」，不开 Unity 编辑器——
模板是工具作者在 Unity 里一次性批量压好的（530 个 body + 378 个 hair），你只负责挑对应的那个填进面板。

### 网盘素材包

上表里两项**大件、且不随插件版本走**的东西，**不放 GitHub，统一在百度网盘提供**。
网盘上是一个 `libraries` 文件夹（约 19.8 GB），下载到任意目录，里面三个子目录：

| 子目录 | 内容 | 对应上表 | 大小 |
|---|---|---|---|
| `assetstudio-body-json/` | 530 套服装的 `Geo_Body.json` + 骨架 JSON | 网格 JSON 资源库（换 body） | 4.5 GB |
| `assetstudio-hair-json/` | 378 套发型的 `Geo_Hair.json` / `Geo_HairProp.json` + 骨架 JSON | 网格 JSON 资源库（换 hair） | 3.3 GB |
| `templates/` | 908 个 Unity 模板 `template_<目标资源名>.bundle` | Unity 模板 bundle | 12 GB |

> 🔗 **百度网盘**：<https://pan.baidu.com/s/1gQCJASpR42gLvmcEfsRj-Q>　提取码 **`es08`**

只换你要的那一类也行：只换装就下 `assetstudio-body-json/` + `templates/`，
`templates/` 里也可以只挑目标资源同名的那一个 `.bundle`。

路径在插件面板里这样填：

- 「选项 2 网格 JSON 资源库」→ 换 body 填 `<你的目录>\libraries\assetstudio-body-json`，
  换 hair 填 `<你的目录>\libraries\assetstudio-hair-json`；
- 阶段 5 的 `R32 模板 bundle` → 在 `<你的目录>\libraries\templates\` 里按目标资源名挑同名文件，
  例如换 `mdl_chr_atbm-cstm-0140_body` 就选 `template_mdl_chr_atbm-cstm-0140_body.bundle`。

## 1.2 安装插件

在 Blender 中打开：

```
编辑 > 偏好设置 > 插件 > 从磁盘安装
```

选择本地构建生成的当前版本插件 ZIP。启用 **GakumasMI** 后，面板出现在：

```
3D 视图 > 右侧边栏（按 N 键）> GakumasMI
```

> 📷 **待截图**：`images/panel-location.png` —— 3D 视图右侧边栏中的 GakumasMI 面板，标出顶部五阶段导航。

### 看到旧英文按钮怎么办

说明装的是旧版。**卸载旧版插件 → 关闭 Blender → 重新打开 → 再安装新版 ZIP**。Blender 不重启有时不会刷新面板。

## 1.3 准备网格 JSON 资源库（自己导，可选）

> **用网盘那份就跳过本节。**下面是想自己从游戏缓存重导（例如游戏更新出了新服装）时的做法。

插件不直接读游戏文件，而是读 AssetStudio 离线导出的 JSON。这一步只做一次，之后所有 mod 复用。

把游戏缓存里的 body AB 文件收集到一个目录里（体积以 GB 计，放仓库外），然后用 `--input`
指向它、`--output` 指向要生成的 JSON 库位置：

```powershell
# 同时导出网格 JSON 和骨架 JSON（推荐）
python tools\export_all_body_json.py --assetstudio <AssetStudio.CLI.exe> `
  --input <放 body AB 的目录> --output <要生成 JSON 库的目录> --skeleton

# 调试：先跑前 5 个
python tools\export_all_body_json.py --assetstudio <AssetStudio.CLI.exe> `
  --input <...> --output <...> --limit 5 --force --skeleton
```

`--assetstudio` 必填（UnityCN 加密要它处理）；`--input` / `--output` 不填会落到脚本内置的
开发机默认路径，多半不是你要的。

输出按 body 资源名分目录，避免同名 `Geo_Body.json` 互相覆盖：

```text
<资源库目录>/assetstudio-body-json/
  mdl_chr_<角色>-cstm-<编号>_body/
    Geo_Body.json            # 网格：顶点 / 权重 / BindPose / 骨骼 hash
    Geo_Body.skeleton.json   # 骨架：骨骼名 / 层级（严格可读时才生成）
```

这个目录整体就是插件"选项 2"要填的 **网格 JSON 资源库**。

> 资源库里 500+ 套服装插件都能自动匹配，你不用关心里面的骨架数据是否齐全。

> 发型资源库来自 `_hair` 包，同时含 `Geo_Hair` 与 `Geo_HairProp` 两个网格。发型换模详见 [[7-发型与发饰]]。

## 1.4 准备打包用的外部 Python

最后一步「导出并打包 bundle」不开 Unity，而是用 **UnityPy** 把你的数据灌进 R32 模板。
这需要一个**你自己装的 Python**——**Blender 自带的那个不行**，它没有 UnityPy，也不该往里装。

1. 装 **Python 3.10 或更高**（推荐 3.11 / 3.12）。下限是 Pillow 要求的，不是插件的限制。
   安装时勾上 **Add python.exe to PATH** 最省事；
2. 装依赖：

   ```powershell
   pip install UnityPy Pillow
   ```

3. 记下它的路径，阶段 5 的 **`外部 Python`** 栏要用：

   ```powershell
   python -c "import sys;print(sys.executable)"
   ```

   打印出来一般是 `C:\Program Files\Python\Python312\python.exe` 这样。
   **在 PATH 上的话那栏保持默认 `python` 即可**，不用改。

> ⚠ Windows 上 `C:\Users\<你>\AppData\Local\Microsoft\WindowsApps\python.exe` 可能是应用商店的
> **占位程序**，点了只弹商店。上面那条命令打印出这个路径就说明你没装真 Python，或者 PATH
> 里商店占位排在前面。

填法与排错详见 [[阶段 4–5：骨架、检查与导出|6-步骤③-导出AB bundle]] 6.3。

## 1.5 一次性检查清单

- [ ] Blender 4.2 打得开，右侧边栏能看到 GakumasMI 面板，按钮是中文
- [ ] 资源包目录里有分目录的 `Geo_Body.json`（每套服装一个 `mdl_chr_*_body/` 子目录）
- [ ] 至少有一个抓帧目录 `FrameAnalysis-*`
- [ ] 命令行 `python -c "import UnityPy, PIL; print('ok')"` 打印 `ok`（打包用的外部 Python 就绪）
- [ ] 手上有目标资源对应的 R32 模板 `.bundle`

五项齐了就可以进入 [[2-核心概念]] 或直接 [[3-快速上手：第一个换装 mod]]。
