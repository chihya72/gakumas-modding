# 6. 阶段 3：材质与贴图

这一阶段把作者的正方形图集和材质分类，转换成游戏实际读取的 t0、t1、t4 与顶点 COLOR 数据。

## 6.1 三张主贴图

| 面板字段 | 通道含义 | 制作要求 |
|---|---|---|
| 基础色 t0 | RGB 为基础色；Alpha 的含义随 body、hair 和透明路线变化 | 必填，正方形 |
| 混合遮罩 t1 | R 阴影阈值，G 光滑度，B 金属度，A 为组件相关数据 | 可留空生成 |
| 暗面材质 t4 | RGB 为同一 UV 下的暗面颜色；A 为材质分支数据 | 可留空生成 |

t4 不是角色身上的投影阴影。它应与 t0 使用相同 UV 和图案，只是颜色更暗或略有偏色。沿用目标服装原来的 t1、t4 会让新 UV 采到旧衣服图案。

body 的 t1.A 主要用于 AO 与间接光数据；hair 的 t1.A 还会影响镜面和旧 HHL 可见性。自定义 hair UV 没有专门处理高光图时，安全生成结果会把 A 设为 0，避免错采原发型高光。

## 6.2 最短正确做法

1. 填 `基础色 t0`。
2. `混合遮罩 t1` 与 `暗面材质 t4` 没有成品时留空。
3. 保持 `中性 t1/t4` 开启。
4. 在材质槽列表逐个选择材质。
5. 为每个槽设置真实的 `材质类型`。
6. body 的第一版全部使用 `不透明`。
7. 点击 `生成游戏材质贴图`。

按钮只有在 t0 已填写且作者模型存在材质槽时启用。

## 6.3 材质槽

材质设置只作用于列表中当前选中的槽：

- `材质类型` 决定生成 t1、t4 和部分描边数据时采用皮肤、布料、皮革、金属、头发或中性预设；
- `渲染方式` 只在 body 显示，默认 `不透明`；
- `明暗范围` 为 `-1` 时使用材质预设，手动调高会减少暗面，调低会扩大暗面。

金属小件需要高光时标为金属；若暗场景里过黑，可以改用较弱的材质预设。不要为了改变颜色而随意改材质类型，基础颜色应在 t0 中处理。

透明方式的前提和交付状态见 [[透明材质|10-透明材质]]。

## 6.4 生成选项

`肤色对齐原版` 只处理标为皮肤的区域。插件把生成后的校色 t0 另存并自动回填，不修改原文件。它用于减少作者身体与原版头部在脖子处的色差。

`几何AO软化阴影` 会从网格凹陷处生成额外 AO，例如腋下、裆部和衣褶内部。它不能改变光滑凸面上的硬光影分界；后者应通过材质的 `明暗范围` 调整。

## 6.5 描边

body 的描边颜色来自顶点 COLOR。可选方式：

| 方式 | 适用情况 |
|---|---|
| 取自基础色 | 通用默认值，导出时按 UV 从 t0 采样 |
| 按材质预设 | 希望不同材质槽使用预设描边 |
| 黑色常量 | 最保守的统一黑色描边 |
| 沿用源模型顶点色 | 源网格已经带有正确的游戏 COLOR 编码 |

选择 `沿用源模型顶点色` 时，网格必须存在名为 `COLOR`、域为 `POINT` 的逐顶点颜色属性，否则导出会拒绝。

`描边宽度`：

- `正常描边`：全网格使用正常宽度；
- `仅安全顶点`：关闭 `GMI_NO_OUTLINE` 或高风险顶点的描边；
- `关闭`：全网格无描边。

hair 使用 `发型描边色档`，按深色、粉红、金浅色或纯黑选择；hairprop 则按材质类型生成安全常量。详见 [[发型与发饰|9-发型与发饰]]。

## 6.6 原生 co 贴图

只要有任一 body 材质槽选择 `原生co`，主流程就会展开独立的：

- `co 基础色 t0 / m_bdyco`，必填；
- `co 混合遮罩 t1`，可留空生成中性图；
- `co 暗面材质 t4/sdw`，可留空生成中性图。

co 使用自己的图集和 UV，不能借 body t0 兜底。未选择原生 co 时，这组输入只放在可选折叠区，不应填写。

## 6.7 发饰与高级通道

制作 hair 且同时有发饰时，展开 `发饰贴图（只在制作发饰时填）`，为 hairprop 提供独立 t0、t1、t4。没有发饰作者网格时保持为空。

`高级：t1 单通道覆盖` 用于已有单通道灰度图的作者。四个通道都填时直接合成；只填部分时，插件先按材质预设生成完整 t1，再覆盖已提供的通道。普通项目不需要打开。

## 6.8 本阶段的红色提示

- 没有作者模型：返回阶段 2。
- 作者模型没有有效材质槽：先为材质槽指定 Blender 材质。
- 没有基础色 t0：必须提供正方形基础色。
- 存在原生 co 材质但没有独立 co t0：补 co 图集，或把该槽改回不透明。
