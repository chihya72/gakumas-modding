# 10. 透明材质

body 材质槽目前有三种 `渲染方式`。它们不是同一效果的三个质量档，而是不同渲染路径。

| 方式 | 适合 | 目标前提 | 当前公开版本可交付 |
|---|---|---|---|
| 不透明 | 绝大多数身体、衣物和硬件 | 无特殊前提 | 是 |
| 原生co | 镂空、网眼和硬边 Alpha 裁剪 | 目标 body 必须有 m_bdyco 材质段 | 是 |
| 自建半透明 | 薄纱、罩裙等连续透明度 | runtime 须为带烘焙半透明的版本（2026-09-07 之后） | 是，见 10.4 |

第一版应全部使用不透明。只有实际需要 Alpha 的材质槽才改变。

## 10.1 不透明

`不透明` 使用目标 body 的普通材质段，阴影、深度、SSAO 和描边行为最稳定。

即使 t0 文件带 Alpha，不透明材质也不会因此自动变成透明。不要用图片查看器里的透明预览判断游戏材质路线。

## 10.2 原生 co 的前提

`原生co` 借用目标服装已有的第二材质段 `m_bdyco`。目标 profile 和 R32 模板必须真的包含该段。

如果目标 body 只有普通 `m_bdy` 一段，导出会报目标不支持 co。解决办法只有两个：

- 把作者材质改回不透明；
- 选择并重新抓取一个本身含 m_bdyco 的目标服装。

不能只换模板而不换阶段 1 的目标配置档，两者必须属于同一个目标资源。

## 10.3 原生 co 的贴图

只要有一个材质槽设为原生 co，阶段 3 会把 `原生 co 贴图` 变成主流程并要求独立 t0：

| 字段 | 要求 |
|---|---|
| co 基础色 t0 / m_bdyco | 必填；RGBA，Alpha 用于裁剪 |
| co 混合遮罩 t1 | 可提供；为空时使用中性结果 |
| co 暗面材质 t4/sdw | 可提供；为空时使用中性结果 |

co 网格必须使用 co 图集自己的 UV。插件不会退回使用普通 body t0，因为两套图集的 UV 通常不同。

原生 co 应按镂空或 Alpha Test 理解：像素通过门槛就显示，不通过就裁掉。不要用它制作平滑的 20%、50%、80% 透明度。

透明区的 RGB 需要向外扩色。只把 Alpha 清零、RGB 留纯黑，会在双线性采样边缘产生黑线或黑块。

## 10.4 自建半透明（烘焙半透明）

`自建半透明` 由 runtime 在游戏里**每帧烘出当前姿态、在景深之后补画**，镜子里也会画；遮挡用原版的
深度，光照读原版的角色灯表和场景阴影色，所以暖光、蓝光、换舞台都会跟着变。2026-09-07 在向日葵
舞台和带镜子的房间里实机验收通过。

作者要做的只有：

1. 把薄纱那个材质槽的 `渲染方式` 选成 `自建半透明`；
2. 拖 `半透明度`（薄纱 0.5 左右，厚一点 0.75）；
3. 正常导出。

导出器会把它写成 `mod.json` 里的 `transparentMaterials` 条目并声明 `_GmiBakedAfterDof`，其余
（关掉旧的前向/原生透明趟、队列、镜面）全部由 runtime 接管。不需要复制几何、不需要在游戏目录放
任何开关文件。

字段含义：

- `半透明度`：整体不透明度，与 t0 Alpha 相乘；
- `半透明 toon 强度`：1 使用 t1、t4 卡通明暗，0 接近平涂；
- `半透明段用 co 图集`：该材质 UV 落在 co atlas 时开启，否则使用普通 body t0。

半透明段不另出贴图：它复用 body（或 co）图集的 t0 / t1 / t4，UV 必须落在那套图集里。

边界（已知、暂不打算在这一版解决）：

- 没有阴影贴图和环境高光，只有角色灯表 + 场景阴影色 + ramp；
- 多层纱重叠处透明度会叠加，前后两层 50% 叠出来约 75%；
- 透明补不了缺失的几何 —— 长裙下面若没有身体网格，透过纱看到的就是空的；
- 角色出现后最多约 1 秒（60 帧）才被扫到并开始显示；
- 镜面补绘不写原版 stencil，镜子边缘可能有溢出。

## 10.5 材质与图集组织

不透明槽会归并到普通 body 材质段；原生 co 槽归并到 m_bdyco；自建半透明槽会占新增材质段。

同一路线中的多个作者材质槽仍应共享对应 atlas。不同槽使用不同独立贴图时，单靠设置渲染方式不能解决图集问题。

## 10.6 常见错误

- `存在原生co材质，但没有填写它自己的基础色贴图`：补 co t0，或改回不透明。
- `目标 body 只有 bdy 一段`：当前目标不支持原生 co。
- co 边缘黑：对透明区 RGB 做外扩色，不要改 Alpha 门槛来掩盖。
- 自建半透明在游戏里不显示：看 `gakumas-mod/mod-plugin.log` 里的 `Transparent materials refused`。常见原因是 runtime 太旧（`gmi_shaders.bundle` 没有 `GmiBakedAfterDof` pass）或半透明段的贴图没导出。

其他现象见 [[常见问题与排错|11-常见问题与排错]]。
