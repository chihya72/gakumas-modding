## 2. 首次游戏内复核

进入候选场景后，逐项确认：

- [ ] 场景可以从固定入口重复进入；
- [ ] 每次进入均为同一角色、同一服装；
- [x] 画面中只有一名主要角色；
- [ ] 可以暂停或维持相对稳定的角色姿势；
- [ ] 镜头位置可复现，或至少可保持固定；
- [ ] 隐藏对话 UI 后没有持续遮挡身体的大面积 UI 或特效；
- [ ] 近景下脸、头发、身体、鞋子和饰品均可观察；
- [ ] 重进场景后主要 Drawcall 没有明显随机变化；
- [x] 3DMigoto Hunting HUD 正常显示；
- [ ] `d3d11_log.txt` 正常生成且不含注入错误。

若任一关键项失败，先更换场景，不更换角色；若服装无法在合适场景中稳定使用，再更换服装。
